# 화면 레퍼런스 — 실제 운영 중인 항만 사이트

2026-11-12에 직접 열어 본 사이트만 적었다. 화면마다 어느 사이트의 문법을 따랐는지 남긴다.

| 사이트 | 본 화면 | 가져온 것 | 우리 화면 |
|---|---|---|---|
| [SK Seagate](https://skseagate.skinnovation.com/view/seagate/abo/marinter/marinter01) (울산 CLX 항무 웹사이트) | 공개 메인 · Marine Terminal 페이지, 사용자가 준 Berthing Schedule 캡처 | 상단 링크줄, 흰 헤더(로고 · 가운데 메뉴 · 회색 알약 버튼 · 사이트맵), 회색 바탕, 대문자 왼쪽 트리(+/− 상자), 얇은 밑줄이 있는 제목, 조회 조건표, 빨간 검색 버튼, 어두운 바닥글 | 화면 전체 틀 · Berthing Schedule |
| [부산항 신선대감만터미널 정보조회서비스](https://info.bptc.co.kr/) | 본선작업현황(첫 화면), 선석배정 현황(T), 선석배정 현황(G) | 굵은 제목 + 회색 한 줄 설명, 넓은 탭(신선대 / 감만), 선석별 열에 진행률 배지(초록 · 빨강)와 선박 그림, 왼쪽 진한 머리칸, 조회기간 라디오(4일 · 일주일 · 한달 · 직접 입력), '▶ 조회기간' 줄과 프린트 · 엑셀 버튼, 날짜를 가로로 두고 상자 모서리에 시각을 적는 선석 그래프, 공지 패널과 바로가기 타일 | 대시보드의 선석 작업현황 · 선석배정 그래프 · 표 |
| 사용자가 준 선석배정 표 캡처 | 출항(회색) · 작업중(노랑) · 계획(하늘) 행 색과 범례, '전체 조회 건수' 빨간 숫자, Print | 상태별 행 색 · 범례 · 건수 | Berthing Schedule · 대시보드 표 |
| [울산항만공사 PortWise](https://www.upa.or.kr/portwise/vsl/) | GIS 지도, 선박 카드 | 선박 모양 마커(목적지 울산 / 그 외 색), 아래쪽 범례, 카드 구성(AIS 실시간 위치 · Port-MIS 신고 두 칸, 업데이트 시간, 선박 그림 위 톤수 · 흘수 · 길이 · 폭, 국적 · 선박명 · MMSI · 호출부호 · 선박 타입 · 위치 · 항차 사용 · 시설 사용 표, 출발지 → 목적지, Status · Speed · Course, 아래 버튼) | 선박 지도 · 선박 카드 |

우리 서비스에 맞춘 것

- 컨테이너 터미널의 크레인 · 컨테이너 그림 대신 액체부두(제티 · 로딩암 · 탱커)로 그렸다.
- 진행률 배지는 작업 진행률이고, 체선이 예상되면 빨강이다(부산항 화면에서 빨강 = 늦음).
- 행 색에 '체선'(빨간 글자)을 더했고, 컨테이너 표의 Closing Time 자리에 정박종료(Laytime 끝)를 빨간 굵은 글자로 둔다.
- PortWise 카드의 '대기 시간 예측' · '선박 상세보기' 자리에 '체선료 산출 근거'를 둔다.
