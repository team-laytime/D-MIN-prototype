### 먼저 볼 것 — 탭 2에서 빠졌거나 어긋난 곳

탭 2 본문에서 단어를 직접 찾아 확인했다. 탭 3(요구사항 리뷰)이 이미 짚은 것은 ✔로 표시했다.

1. ✔ **조석**: 원문이 꼽은 제약 4종(접안 가능 제품·조석·일출/일몰·기상) 중 조석이 탭 2에 한 번도 안 나온다(탭 1에는 6번). 탭 3 7장도 같은 지적이다. → FR-37, FR-84
2. **일기예보·풍속 연동**: 원문과 캔버스는 공공데이터로 기상·조석·일출·일몰을 받는다고 했는데 탭 2 FR-11은 일출·일몰만 있다. 탭 3은 기상을 사용자 입력으로 정리하자는 쪽이라, 연동을 살릴지 먼저 정해야 한다. → FR-27, FR-83, FR-85, FR-86
3. ✔ **메일 초안**: 원문 기능 4는 "메일과 보고용 Report"인데 탭 2 FR-09는 보고서 초안만 말한다('메일' 0번). 탭 3도 FR-09를 나누자고 했다. → FR-66
4. **입출항 작업 지시자**: 원문 사용자 3역 중 이 역할을 위한 요구가 탭 2에 없다('입출항'·'작업 지시' 0번). 체선 지불 부서는 '체선료 담당자'로 계산 쪽만 있다. → FR-63, FR-64, FR-67, FR-91
5. ✔ **남은 리스크**: 날씨 급변·설비·탱크·긴급 출하·현장 안전이 원문 기능 3의 예시인데, 탭 2 FR-06은 다른 이름으로 바뀌어 '긴급 출하'와 '현장 안전'이 이름으로 안 남았다('긴급 출하'·'현장 안전' 0번). 탭 3은 5종 점검표로 되돌리자고 했다. → FR-58
6. **정답 세트**: 성공기준 ①이 "정답 세트 대비 일치율 100%"인데 정답 세트를 만들고 관리하는 요구가 없다('정답 세트' 0번). 탭 3 7장은 정답 세트의 규모를 적자고만 했다. → FR-75, FR-76, FR-77
7. ✔ **시간대·반올림·단위**: 한국 표준시와 반올림 단위가 탭 2에 없고('KST' 0번), 통화는 '환산하거나 합산 불가' 택일로 남아 있다. 탭 3 신규-08과 Q-09·Q-18이 짚었고, 물량·요율 단위는 아직 아무도 안 물었다. → NFR-44, NFR-45, NFR-48, FR-35
8. **멀티 Agent 구성**: 캔버스 제안 솔루션이 멀티 Agent인데 Agent별 역할·경계를 요구로 적은 곳이 없다. → FR-87, FR-88
9. **끊김 없는 완주**: 성공기준 ③인데 LLM이 막혔을 때와 발표 리허설을 다룬 요구가 없다. 탭 3 NFR-05 조치는 API만 다룬다. → NFR-19, NFR-20, NFR-77
10. **Must 쏠림**: 탭 2는 45개 중 36개(80%)가 Must다(기능 33개 중 30개, 비기능 12개 중 6개). 6주에 6명이 36개를 다 하려면 Must끼리 순서를 가를 기준이 필요하다. 이번 후보는 대부분 Should·Could로 매겼다

## 1. 어떻게 뽑았나

여섯 가지 눈으로 훑었다.

1. **원문·캔버스 한 줄씩**: 문장마다 "이걸 확인하는 요구가 있나?"를 물었다
2. **데모 흐름 7단계**: 입력 → 계산 → 비교 → 리스크 → 선택 → 보고서 → 검증. 단계마다 정상 / 예외 / 반복(다시 하기)을 봤다
3. **사람별**: 스케줄러, 입출항 작업 지시자, 체선료 담당자, 검증 담당자, 개발 담당자, 운영자 각각 "이 사람이 할 일이 있나?"
4. **품질 점검표**: 성능, 신뢰성, 보안, 사용성, 유지보수, 이식성, 데이터 품질, 설명 가능성, 운영, 법·지식 (ISO/IEC 25010의 품질 특성 분류를 따랐다. 링크는 확인하지 않았다)
5. **이미 있는 코드가 하는 일**: `clock/`·`journeys/`·`prototype/`이 하는데 문서에 없는 것
6. **탭 3 리뷰와 대조**: 같은 제안이 이미 있으면 출처에 표시하고 6절에 모았다

**우선순위 규칙**은 10번 문서와 같다. Must는 캔버스 MVP·성공기준을 지키는 데 빠지면 안 되는 것, Should는 포함 범위나 원문이 권하는 것(없어도 흐름은 돈다), Could는 시간이 남으면 하는 것이다.

**읽는 법**

- 표는 구글 문서 탭 2와 같은 6열(ID · 구분 · 요구사항 · 우선순위 · 수용기준 · 출처)이라 칸 그대로 붙여 넣을 수 있다
- 각 묶음 머리의 "이미 있음" 줄은 탭 2에 있는 관련 번호다. 같은 내용을 다시 적지 않았다
- 우선순위와 숫자는 **제안**이다. 숫자는 5절에 모았다
- 출처의 **[확인 필요]**는 멘토 답이 있어야 확정되는 것이다. **[제안 값]**·**[팀 제안]**은 근거 문서가 아니라 우리가 정한 것이다
