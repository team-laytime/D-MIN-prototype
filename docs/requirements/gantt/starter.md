# 시작용 간트 표 — 우리 팀

> 이 파일은 `make_gantt.py`가 `tasks.csv`·`gantt.config.json`에서 **자동 생성**한다. 직접 고치지 말고 원본을 고친 뒤 `python3 make_gantt.py`를 다시 실행한다. 여기에 담을 작업은 `gantt.config.json`의 `starter`로 고른다.

- [`../00-start-here.md`](../00-start-here.md) §3의 시작용 표를 우리 일정으로 채운 것이다.
- 기간: **11/4(수) ~ 12/16(수)** (42일). 마감일은 **가정 (시작일부터 6주)** 이다. 알게 되면 `deadline`만 고친다.
- 팀: **5~6명** (2026-11-04 사용자 응답). 역할 6개(PM·도메인·엔진·에이전트·평가·발표)를 한 사람이 하나씩 맡는다. 5명이면 한 명이 두 역할을 겸임하고, 일이 겹치는 기간이 짧은 쌍(도메인+평가 또는 PM+발표)을 고른다 [추천]. '전원'은 모두가 함께 하는 일이다.
- 전체 일정 34개 작업 중 핵심 16개만 골랐다. 전부 보려면 [`gantt.md`](gantt.md), 차트는 [`gantt.html`](gantt.html)(처음에 '시작용' 보기)이다.

## 쓰는 법

1. [`starter.csv`](starter.csv)를 Google Sheets나 Excel로 가져온다 (파일 → 가져오기). 한글이 깨지면 인코딩을 UTF-8로 고른다.
2. `담당(이름)` 칸에 사람 이름을 적는다. 한 줄에 한 명이다.
3. 일을 시작하면 `상태`를 "진행 중", 끝나면 "완료"로 바꾼다. 매주 월요일 5분, 이 표를 같이 본다.
4. 시트로 옮긴 순간부터 시트가 팀의 일정이다. 저장소의 `tasks.csv`와 시트 중 **하나만 원본**으로 정한다. 저장소를 원본으로 쓰면 `tasks.csv`를 고치고 다시 생성한다.
