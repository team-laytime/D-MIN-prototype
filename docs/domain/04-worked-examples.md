# 레이타임·체선료 계산 예제집 (Golden Set 씨앗)

- 작성일: 2026-11-02
- 갱신: 2026-11-02 — CLOCK 프로토타입(`../../clock/`) 검증 결과 반영. TC-01b 도착 시각, TC-03 쟁점(야간 대기) 추가, SOF 표의 계산 행 표시, 금액 반올림 규칙, TC-05b 번호. 정답 숫자는 바뀌지 않았다.
- 용도: (1) 팀원이 손으로 따라 계산하며 규칙을 익힌다. (2) 같은 입력·정답 쌍을 CLOCK 룰 엔진과 CLAIM 모듈의 테스트 케이스(TC)로 쓴다.
- 공통 조건 [가정]: Asbatankvoy 기반 항해용선, 통지시간 6시간, 레이타임은 running hours, 종료는 호스 분리. 울산 CLX 양하. 선박명·시각·요율은 모두 **가상**이다. 날짜는 D1, D2… 상대 표기(현지시각).
- 공통 터미널 룰 [사실, SEAGATE Entry Guide]: SK Buoy(SBM)는 야간 계류 불가. SK3~8 선석은 공선 30,000GT 이상·적재 25,000GT 이상 선박의 접안이 주간만 가능, 이안은 24시간. "주간"은 07:00~17:30으로 둔다 [가정].
- 금액 표기 [추천]: 시간은 분 단위로 계산하고, 이 문서의 금액은 **달러 단위로 반올림**해 적는다(예: 3.5h × 50,000/24 = 7,291.67 → 7,292). 엔진·청구 대조는 센트까지 계산하고, 이 문서의 정답과 비교할 때만 같은 방식(0.5 이상 올림)으로 반올림한다.
- SOF 표 읽는 법: *(계산)* 표시 행(통지시간 만료·레이타임 개시·체선 개시)은 SOF 원문 사건이 아니라 이해를 돕기 위해 끼워 넣은 계산 결과다. INTAKE·CLOCK의 입력으로 쓰지 않고 정답 검증에만 쓴다. *(선석 가용)* 행처럼 다른 배의 사건은 SOF 이벤트가 아니라 선석 가용 시각(`06` §9 `berth_ready_at`)으로 넣는다. 행 번호는 표의 위에서부터 센다(계산 행 포함). CLOCK 계산서의 "SOF 행"이 이 번호다.

## 예제 1 (TC-01) — SBM 야간 계류 금지로 대기했지만 체선료 없음

**조건**: VLCC "HANRIVER STAR"(가상) 300,000 DWT, 원유 약 200만 배럴, SK2 Buoy(SBM). 이 항구 허용 레이타임 36h [가정: 총 72h 중 선적항에서 36h 사용]. 요율 USD 120,000/일.

**SOF**

| 시각 | 사건 |
|---|---|
| D1 02:00 | 묘박지 도착, 투묘 |
| D1 02:30 | NOR 제출·수령 |
| D1 06:00 | 양묘, SBM으로 이동 시작 (주간 계류를 위해 대기 후 이동) |
| D1 08:00 | 계류 완료 (finished mooring = all fast) |
| D1 08:30 | *(계산)* 통지시간 만료 (NOR+6h) |
| D1 09:00 | 호스 연결 |
| D1 09:30 | 양하 개시 |
| D2 18:30 | 양하 완료 (33h) |
| D2 19:30 | 호스 분리 |
| D2 20:30 | 서류 완료, 이안 |

**계산**

| 항목 | 값 |
|---|---|
| 레이타임 개시 | min(D1 08:30, D1 08:00) = **D1 08:00** (접안이 먼저) |
| 레이타임 종료 | D2 19:30 |
| 경과 | 35h 30m |
| (−) 이동 D1 06:00~08:00 | 0 (개시 전이라 이미 미산입) |
| 사용 | **35h 30m** |
| 허용 | 36h |
| 체선 | **0** (여유 30m) |

**교훈**: 야간 계류 금지로 NOR 후 5.5시간을 기다렸지만 통지시간 6시간 안에 들어와 레이타임 손실은 없었다. 다만 여유가 30분뿐이라 어떤 추가 지연도 바로 체선료가 된다. EXPOSURE 모듈은 이 "여유 30분"을 경고로 띄워야 한다.

**변형 1b (TC-01b)**: 묘박지 도착(투묘)과 NOR 제출·수령이 모두 전날 D0 20:00이었다면(도착보다 먼저 낸 NOR은 무효라 도착 시각도 함께 정한다. 나머지 SOF 행은 예제 1과 같다) 통지시간 만료 = D1 02:00 → 개시 D1 02:00. 사용 = D1 02:00 → D2 19:30 = 41h 30m, 단 이동(06:00~08:00) 2h는 개시 후이므로 공제 → 39h 30m. 체선 3h 30m × 120,000/24 = **USD 17,500**. 야간 계류 금지가 그대로 돈이 된 경우다. 이 대기를 "용선주 통제 밖"(cl.6)으로 볼지, "reachable on arrival" 위반(용선주 부담)으로 볼지는 쟁점이며, 판례 흐름은 용선주 부담 쪽이다 [확인 필요, `07` 참조].

## 예제 2 (TC-02) — 선석 점유 대기 후 체선, 이동 시간 공제

**조건**: Aframax "DONGHAE PIONEER"(가상) 105,000 DWT, 원유, SK8. 허용 30h [가정]. 요율 USD 55,000/일. SK8은 앞 선박이 D2 06:00까지 점유.

**SOF**

| 시각 | 사건 |
|---|---|
| D1 14:00 | 묘박지 도착, NOR 제출·수령 |
| D1 20:00 | *(계산)* 통지시간 만료 → 레이타임 개시 (선석 점유 중) |
| D2 06:30 | 도선사 승선, 양묘, 이동 시작 |
| D2 08:00 | 접안 완료 (all fast, 주간) |
| D2 09:00 | 호스 연결 |
| D2 09:30 | 양하 개시 |
| D3 05:30 | 양하 완료 (20h) |
| D3 06:30 | 호스 분리 |

**계산**

| 항목 | 값 |
|---|---|
| 레이타임 개시 | min(D1 20:00, D2 08:00) = **D1 20:00** |
| 종료 | D3 06:30 |
| 경과 | 34h 30m |
| (−) 이동 D2 06:30~08:00 | 1h 30m (ASB-07-SHIFTING-EXCL) |
| 사용 | **33h 00m** |
| 허용 | 30h |
| 체선 | **3h 00m** |
| 체선료 | 3 × 55,000 / 24 = **USD 6,875** |

**교훈**: 대기 10.5시간이 체선료의 원인이다. 이동 시간 공제는 금액은 작지만 실무에서 가장 자주 다투는 항목 중 하나다. EXPOSURE 모듈은 D1 20:00 시점에 "앞 선박 종료 예정 D2 06:00 + 주간 접안 → 체선 3h 예상"을 미리 낼 수 있어야 한다.

## 예제 3 (TC-03) — 묘박지에서 이미 체선 돌입, 체선 중 이동, 기상 중단 반액

**조건**: VLCC "ULSAN GLORY"(가상) 310,000 DWT, 원유(부분 적재), SBM. 허용 36h [가정]. 요율 USD 120,000/일. SBM은 앞 VLCC가 D2 19:00까지 점유. 야간 계류 불가.

**SOF**

| 시각 | 사건 |
|---|---|
| D1 10:00 | 묘박지 도착, NOR 제출·수령 |
| D1 16:00 | *(계산)* 통지시간 만료 → 레이타임 개시 (대기) |
| D2 19:00 | *(선석 가용)* 앞 선박 이안. 야간이라 계류 불가, 계속 대기 |
| D3 04:00 | *(계산)* 허용 레이타임 36h 소진 → **체선 개시 (묘박지에서)** |
| D3 07:00 | 양묘, SBM 이동 시작 |
| D3 09:00 | 계류 완료 |
| D3 10:00 | 호스 연결 |
| D3 10:30 | 양하 개시 |
| D3 22:00 | 강풍으로 터미널 지시에 따라 양하 중단 |
| D4 04:00 | 양하 재개 (중단 6h) |
| D4 19:30 | 양하 완료 (실작업 27h) |
| D4 20:30 | 호스 분리 |

**계산**

| 항목 | 값 |
|---|---|
| 레이타임 개시 | **D1 16:00** |
| 체선 개시 | D1 16:00 + 36h = **D3 04:00** |
| 종료 | D4 20:30 |
| 체선 시간 | D3 04:00 → D4 20:30 = **40h 30m** |
| 야간 계류 금지 대기 D2 19:00~D3 07:00 (12h) | 앞 선박 이안 뒤 선석은 비었지만 야간이라 계류 불가. 레이타임 중 9h(D2 19:00~D3 04:00)는 reachable on arrival로 **산입**(기본 계산, ASB-09-REACHABLE). 용선주는 cl.6 "통제 밖 지연" 예외(ASB-06-BERTH-DELAY-EXC)로 불산입을 주장할 수 있음 → 쟁점(`05` §7-2). 9h를 빼면 체선 개시가 D3 18:00으로 밀려 약 USD 117,500(선석 전환 시간 0 가정, 60분이면 122,500) |
| 이동 D3 07:00~09:00 (2h) | 체선 중 발생. cl.7은 "used laytime"만 언급 → once on demurrage 원칙상 **산입**(선주 입장). 용선주는 공제 주장 가능 → 쟁점 |
| 반액 구간 | 폭풍 중단 D3 22:00~D4 04:00 = **6h** (ASB-08-HALF-RATE, 체선 중 발생) |
| 전액 구간 | 40h 30m − 6h = 34h 30m |
| 체선료 | 34.5 × 120,000/24 + 6 × 120,000/48 = 172,500 + 15,000 = **USD 187,500** |
| 용선주 대안 계산(이동 2h 공제 시) | 32.5 × 5,000 + 6 × 2,500 = **USD 177,500** (차이 10,000) |

**교훈**: (1) 긴 대기와 야간 계류 금지가 겹치면 배가 선석에 닿기도 전에 체선에 들어간다. (2) "once on demurrage"가 실제 금액을 가른다. (3) 반액 적용에는 기상 기록(KMA 관측 데이터)이 증빙이 된다. CLAIM 모듈은 두 계산을 모두 제시하고 쟁점을 표시한 뒤 담당자에게 넘긴다. 자동 판정은 하지 않는다.

**변형 3b**: 폭풍 중단이 체선 개시 전(레이타임 중)에 일어났다면 레이타임은 그대로 흐르고(cl.7에 기상 예외 없음), 반액 적용 여부는 "그 중단 때문에 생긴 체선"으로 볼 수 있는지의 해석 문제가 된다 [쟁점, `07` 함정 6].

## 예제 4 (TC-04) — 펌핑 워런티 미달로 선주 측 공제, 체선료 소멸

**조건**: Aframax "PACIFIC MERIDIAN"(가상) 100,000 DWT, 제품유, SK7. 허용 30h [가정]. 요율 USD 50,000/일. Rider 조항: 전량 24시간 내 양하 또는 매니폴드 100 psi 유지 보증, 미달 시 초과 시간은 선주 부담. 터미널은 "육상 제한 없음" 확인서 발행.

**SOF**

| 시각 | 사건 |
|---|---|
| D1 06:00 | 묘박지 도착, NOR 제출·수령. 선석 비어 있음 |
| D1 06:30 | 양묘, 이동 |
| D1 08:00 | 접안 완료 (주간) |
| D1 09:00 | 호스 연결 |
| D1 09:30 | 양하 개시 |
| D2 16:30 | 양하 완료 (31h). 펌핑 로그: 평균 매니폴드 압력 60 psi, 육상 배압 제한 없음 |
| D2 17:30 | 호스 분리 |

**계산**

| 항목 | 값 |
|---|---|
| 레이타임 개시 | min(D1 12:00, D1 08:00) = **D1 08:00** |
| 종료 | D2 17:30 |
| 경과 | 33h 30m |
| (−) 이동 | 0 (개시 전) |
| (−) 펌핑 초과 | 실양하 31h − 보증 24h = **7h** (RIDER-PUMPING) |
| 사용 | **26h 30m** |
| 허용 | 30h |
| 체선 | **0** |
| 공제 없었다면 | 33h 30m → 체선 3h 30m → USD 7,292 |

**교훈**: 터미널(SK)의 배압·수용 기록이 "선박 탓"을 입증하는 유일한 근거다. 터미널 데이터가 곧 체선료 방어 수단이며, CLAIM 모듈은 펌핑 로그와 터미널 기록을 자동 대조해야 한다.

## 예제 5 (TC-05) — 조기 NOR(무효)과 개시 시점 분쟁

**조건**: MR "GEOJE SPIRIT"(가상) 48,000 DWT, 케미컬, SK7. 허용 24h [가정]. 요율 USD 26,000/일. 선장은 묘박지 도착 2시간 전, 항계 밖 항해 중에 NOR을 보냈다. 재제출 없음. 대리점은 수령만 하고 유효성에 대해 언급하지 않았다.

**SOF**

| 시각 | 사건 |
|---|---|
| D1 11:00 | NOR 송신 (항해 중, 항계 밖) |
| D1 13:00 | 묘박지 도착, 투묘 |
| D2 06:00 | 양묘, 이동 |
| D2 07:30 | 접안 완료 (주간) |
| D2 08:30 | 호스 연결 |
| D2 09:00 | 양하 개시 |
| D2 21:00 | 양하 완료 (12h) |
| D2 22:00 | 호스 분리 |

**선주 청구 (NOR 유효 전제)**

| 항목 | 값 |
|---|---|
| 개시 | D1 17:00 (NOR 11:00 + 6h) |
| 종료 | D2 22:00 → 경과 29h |
| (−) 이동 1h 30m | |
| 사용 | 27h 30m, 허용 24h → 체선 3h 30m |
| 청구액 | 3.5 × 26,000/24 = **USD 3,792** |

**용선주 검토 (NOR 무효)**

| 입장 | 개시 | 사용 | 결과 |
|---|---|---|---|
| 무효 NOR, 재제출 없음, 용선주가 이의 없이 하역 → 하역 개시 시점부터(The Happy Day 논리) | D2 09:00 | 13h | 체선 **0** |
| (TC-05b) 만약 D1 13:00 도착 직후 NOR을 재제출·수령했다면 (SOF는 위와 같고 도착 행에 재제출을 더함) | D1 19:00 | 27h − 1.5h = 25h 30m | 체선 1h 30m = **USD 1,625** |

**교훈**: NOR 유효성 하나가 청구액을 0에서 3,792달러까지 바꾼다. CLAIM 모듈은 NOR 시각을 AIS·SOF의 묘박지 도착 시각과 대조해 "도착 전 NOR"을 자동 플래그하고, 대리점의 수령 서명이 하자 포기(waiver)로 해석될 수 있음을 함께 표시한다.
