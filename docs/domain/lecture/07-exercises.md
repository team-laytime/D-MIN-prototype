## 7-1 (M2) recap 읽기 — TC-E01
다음 recap에서 룰 엔진 입력값을 추출하라.
```
M/T SEORAK TRADER — MR 50,000 DWT
LOAD 1SP YEOSU   DISCH 1SP ULSAN
LAYCAN 05-07 DEC 2026
LAYTIME 60 HRS SHINC TOTAL REVERSIBLE
DEMURRAGE USD 28,000 PDPR
NOR ATDNSHINC 6 HRS NOTICE, WIBON
PUMPING WARRANTY 24 HRS / 100 PSI
TIME BAR 60 DAYS FULLY DOCUMENTED FROM COMPLETION OF DISCHARGE
CP FORM ASBATANKVOY + RIDER
```
**질문**: (a) 총 허용 시간과 가역 여부 (b) 요율과 시간당 금액 (c) NOR 제출 가능 시각과 통지시간 (d) 펌핑 보증 (e) 시효와 기산점 (f) WIBON의 효과.

**해설**: (a) 60h, 선적·양하 합산 가역. (b) USD 28,000/일 = USD 1,166.67/h. (c) 주야·일·공휴일 무관 제출 가능, 수령 후 6시간. (d) 전량 24시간 내 또는 매니폴드 100 psi 유지, 미달 시 초과 시간 선주 부담(육상 제한 없을 때). (e) 양하 완료 후 60일 내 완전한 서류로 청구, 미이행 시 소멸. (f) 선석이 비어 있지 않아도 NOR 유효 → 대기 산입.

## 7-2 (M2) 두 겹 계약과 갭 — TC-E02
SK가 제품을 CFR로 팔아 **SK가 용선주**다. 용선계약: 총 72h 가역, 요율 USD 50,000/일. 매매계약: 매수인의 양하항 허용 36h, 체선료는 용선계약 요율과 같음.
(a) 선적항(울산) 사용 30h, 양하항 사용 40h. 선주에게 내는 돈과 매수인에게 받는 돈은? (b) 선적항 40h, 양하항 35h라면?

**해설**:
(a) 용선계약: 30+40 = 70h ≤ 72h → 선주에게 0. 매매계약: 양하항 40−36 = 4h → 매수인에게 4 × 50,000/24 = **USD 8,333.33** 청구 가능. 갭 +8,333(SK 이익. 선적항을 빨리 끝낸 덕).
(b) 용선계약: 40+35 = 75h → 3h 체선 → 선주에게 3 × 50,000/24 = **USD 6,250** 지급. 매매계약: 양하항 35h ≤ 36h → 매수인에게 0. 갭 −6,250(울산 선적 지연은 SK 자신의 비용).
**교훈**: 갭은 양방향이며, 울산(자사 터미널) 지연은 어느 쪽이든 SK 비용이 된다.

## 7-3 (M3) 개시 판정 — TC-E03
NOR 수령 D1 09:00. (a) 접안 완료 D1 11:30 (b) 접안 완료 D1 16:00. 각각 개시 시각은?

**해설**: 개시 = min(NOR+6h = D1 15:00, 접안 완료). (a) **D1 11:30** (b) **D1 15:00**. (a)에서 통지시간 6시간을 더 주지 않는다는 점에 주의.

## 7-4 (M3) 기본 계산, 체선 없음 — TC-E04
Suezmax, 허용 36h, 요율 USD 70,000/일. SOF: NOR 수령 D1 22:00 → 통지 만료 D2 04:00 → 선석 비어 있으나 주간 접안 규칙으로 D2 05:30 양묘 → 07:00 접안 완료 → 08:00 호스 연결·양하 개시 → D3 08:00 양하 완료(24h) → 09:00 호스 분리.

**해설**: 개시 = min(D2 04:00, D2 07:00) = **D2 04:00**. 종료 D3 09:00. 경과 29h. 이동 D2 05:30~07:00 = 1h 30m은 개시 후이므로 공제 → 사용 **27h 30m** ≤ 36h → 체선 **0**, 잔여 8h 30m. (야간 대기 1h 30m은 통지시간 안에 흡수.)

## 7-5 (M3) 대기 + 체선 — TC-E05
7-4와 같은 선박·계약. 단 선석이 D2 20:00까지 점유되어 야간을 넘겨 D3 05:30 양묘 → 07:00 접안 → 08:00 양하 개시 → D4 08:00 완료 → 09:00 호스 분리.

**해설**: 개시 D2 04:00. 종료 D4 09:00 → 경과 53h. 이동 D3 05:30~07:00(1h 30m): 그 시점까지 산입 누계 25h 30m < 36h → 레이타임 중 → **공제**. 사용 = 53 − 1.5 = **51h 30m**. 체선 = 51.5 − 36 = **15h 30m**. 체선 개시 시각: D3 07:00 이후 10h 30m 더 세면 **D3 17:30**. 금액 = 15.5 × 70,000/24 = **USD 45,208.33**.
플래그: NIGHT_WAIT(D2 20:00~D3 05:30 대기 중 야간 규칙 분), BERTH_OCCUPIED.

## 7-6 (M3) 체선 중 이동 쟁점 — TC-E06
NOR 수령 D1 06:00, 선석 점유로 대기, 개시 D1 12:00. 허용 30h. 선석 해방 D2 20:00, 야간이라 D3 05:30 양묘, 07:00 접안, 08:00 양하 개시, 20h 양하 → D4 04:00 완료, 05:00 호스 분리. 요율 USD 48,000/일.

**해설**: 체선 개시 = D1 12:00 + 30h = **D2 18:00**(묘박지에서). 종료 D4 05:00. 체선 시간(이동 산입, once on demurrage) = D2 18:00 → D4 05:00 = **35h** → 35 × 2,000 = **USD 70,000**. 용선주 대안(이동 1h 30m 공제) = 33.5h → **USD 67,000**. 차이 USD 3,000. 플래그: SHIFT_ON_DEM, NIGHT_WAIT. 담당자가 결정.

## 7-7 (M3) 반액 — TC-E07
체선 개시 D3 02:00, 접안 중. D3 10:00~16:00 강풍으로 터미널 지시 하역 중단(6h). D3 22:00 호스 분리. 요율 USD 96,000/일.

**해설**: 체선 시간 D3 02:00 → 22:00 = 20h. 반액 구간 6h(접안 중 폭풍, cl.8). 전액 14h × 4,000 = 56,000; 반액 6h × 2,000 = 12,000 → **USD 68,000**(전액이었다면 80,000). 증빙: 터미널 중단 지시 기록 + KMA 풍속.

## 7-8 (M3) 가역 레이타임 — TC-E08
총 72h 가역, 요율 USD 60,000/일. 선적항: 개시 D1 08:00, 종료 D2 20:00, 이동 2h 제외. 양하항 사용 41h.
(a) 체선료는? (b) 비가역 36h/36h였다면?

**해설**: (a) 선적항 사용 = 36 − 2 = 34h → 잔여 38h. 양하항 41h → 체선 3h → 3 × 2,500 = **USD 7,500**. (b) 선적항 34 ≤ 36 → 0. 양하항 41 − 36 = 5h → **USD 12,500**. 같은 사실, 다른 금액. 선적항 SOF가 없으면 (a)를 계산할 수 없다 → LOAD_PORT_UNKNOWN 플래그.

## 7-9 (M4) SOF 오류 찾기 — TC-E09
다음 SOF에서 문제를 5개 이상 찾고 고쳐라.
```
D1 12:40  NOR tendered (vessel 8 nm off Ulsan pilot station)
D1 14:00  Anchored at E-2 anchorage
D1 14:30  NOR accepted by agent
D2 06:30  Anchor aweigh
D2 08:00  All fast SK8
D2 09:00  Hoses connected
D2 09:30  Commenced discharge
D2 15:10  Stopped
D2 17:40  Resumed
D3 05:30 UTC Completed discharge
D3 24:00  Hoses disconnected
(signed: Master, Agent)
```
**해설**: ① NOR을 도착 전(항계 밖 8해리)에 제출 → 조기 NOR, 무효 가능(NOR_EARLY). ② 대리점 "accepted" 문구 → 하자 포기 논란. "received, validity reserved"가 바람직. ③ "Stopped" 사유 없음 → 사유 코드 필수(기상? 탱크? 선박?). ④ D3 05:30이 UTC로 기록 → KST 14:30. 다른 행은 KST로 보여 시간대 혼용(TZ_ERROR). ⑤ "D3 24:00"은 D4 00:00으로 표준화. 단 UTC 보정 후 완료 14:30과 호스 분리의 순서를 재확인. ⑥ 터미널 서명 없음 → 3자 서명 요구. ⑦ 통지시간 만료·개시 시각 계산 전에 NOR 수령 시각(14:30 수령? 12:40 제출?) 확정 필요.

## 7-10 (M5) 청구서 검토 — TC-E10
선주 청구: 체선 32h 30m × USD 55,000/일 = USD 74,479.17. 양하 완료 D+0, 청구 도착 D+70, 시효 90일 서류 완비. 사실관계: ① 접안 완료가 NOR+6h보다 2시간 먼저였는데 계산서는 NOR+6h를 개시로 씀. ② 이동 1h 30m 미공제(레이타임 중). ③ 양하 28h, 펌핑 보증 24h, 터미널 배압 기록상 육상 제한 없음.

**해설**: 시효 내(70 < 90), 서류 완비 전제. 조정: 개시 2h 당김 → 사용 −2h(NOTICE_DOUBLE). 이동 −1h 30m(SHIFT_NOT_DEDUCTED). 펌핑 초과 28−24 = −4h(PUMPING_EXCESS, 육상 제한 없음 입증). 체선 = 32.5 − 2 − 1.5 − 4 = **25h** → 25 × 55,000/24 = **USD 57,291.67**. 차이 **USD 17,187.50**. 회신: 세 항목 각각 근거(SOF 행, cl.7, 펌핑 로그 vs 배압 기록) 인용, without prejudice.

## 7-12 (M6) Golden set 설계 — TC-E12
