이벤트 코드레이타임 역할
ANCHORED도착선 판정, 조기 NOR 대조
NOR_RECEIVED개시 계산의 기준 시각
ANCHOR_AWEIGH이동 시작(제외 구간 시작)
ALL_FAST개시 대안, 이동 종료
OPS_COMMENCED무효 NOR 시 개시 대안
OPS_STOPPED / RESUMED사유 코드 필수: 공제·반액 후보
OPS_COMPLETED펌핑 시간 계산
HOSES_DISCONNECTED종료

흔한 기록 오류

  • UTC와 KST 혼용
  • "24:00" 표기
  • 제출(tendered)과 수령(received) 혼동
  • "stopped"만 있고 사유 없음
  • 터미널 서명 누락
  • 묘박 시각 미기록 → 조기 NOR 판정 불가

SOF는 체선료의 원재료입니다. 왼쪽 여덟 코드만 정확하면 계산서가 나오고, 오른쪽 오류 중 하나라도 있으면 금액이 틀립니다. 연습 7-9의 엉망인 SOF를 조별로 고치게 하세요. Agent의 INTAKE가 이 정규화를 맡고, 사유 코드가 비면 사람에게 묻습니다.
