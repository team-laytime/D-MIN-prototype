M6 · SEAGATE 위에 얹기

SEAGATE는 체선 시간을 잰다. 우리는 그 시간을 돈으로 번역하고 설명한다

SEAGATE가 이미 하는 것

  • 선석 예약 · 원유 재고 예측
  • Berthing Schedule · Berth Optimization · Simulation
  • ETB Change Log · 부두제약관리
  • Cargo Working · Performance Record
  • 체선 리포트 4종 · Demurrage 요약

→ 대시보드 · 솔버는 새로 만들지 않는다

우리가 더하는 것

  • 계약 레이어: 허용 · 요율 · 통지 · 시효 · 반액
  • NOR · SOF 원문과 터미널 기록 대조
  • 계약 기준 레이타임 계산서와 쟁점 플래그
  • ETB 변경 1건의 금액 영향 설명
  • 청구서 대조 · 차이 분해 · 회신 초안 · 승인

→ 기록과 계산 "사이"를 메운다

먼저 확인할 것

  • Demurrage 요약이 시간 지표인가 금액인가
  • 체선사유는 누가 입력하고 무엇에 쓰나
  • Berth Optimization은 실제로 쓰이나
  • ETB 변경 빈도와 통보 방식
  • NOR · SOF 입수 경로
