M3 · 계산 절차 표준

열 단계면 어떤 SOF도 계산서가 된다

  1. 계약 조건 확정: 허용·가역·통지시간·요율·제외·반액·시효
  2. SOF를 표준 이벤트와 현지시각으로 정규화
  3. NOR 유효성 판정 → 개시 시각
  4. 구간 분할: 대기 · 이동 · 접안 · 하역 · 중단 · 분리
  5. 구간별 산입 · 제외 · 반액 태깅, 체선 전환 시각
  1. 사용 시간 = 산입 합, 체선 = max(0, 사용 − 허용)
  2. 금액 = 전액 × 요율/24 + 반액 × 요율/48, 분 단위 비례
  3. 선주 귀책 공제(펌핑 워런티 등) 적용
  4. 쟁점 플래그와 대안 계산 첨부, 시효 카운트다운
  5. 모든 줄에 룰 ID + SOF 행 + 조항

이 열 단계가 CLOCK 룰 엔진의 뼈대이고, 사람의 손계산과 Agent의 계산이 같은 절차를 따르기 때문에 결과를 서로 검증할 수 있다.
