M3 · 개시 시점

개시 = min( NOR 수령 + 6h , 접안 완료 )

A · 선석이 차 있을 때 — NOR 14:00, 접안은 다음 날

통지시간 6h · 14:00→20:00

개시 20:00 → 대기도 산입된다

B · 선석이 비어 있을 때 — NOR 14:00, 15:30 접안 완료

개시 15:30 (all fast) → 남은 통지시간 4h 30m은 사라진다

접안 완료 = 부두는 all fast, SBM은 finished mooring. 수령(received) 시각이 기준이며 제출 시각이 아니다.

선주 계산서가 접안이 먼저인데도 NOR+6h를 개시로 쓰면 이중 계산이다(차이 사유 NOTICE_DOUBLE).
