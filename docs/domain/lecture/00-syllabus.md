# 체선료 도메인 집중 강의 — 실라버스

- 작성일: 2026-11-02
- 대상: SKALA 최종 프로젝트 팀원(해운·용선 비전문가, 개발·데이터·PM 혼성)
- 목표: 현업과 같은 단어로 대화하고, 계약서·SOF를 읽어 체선료를 손으로 계산하며, 쟁점을 알아보고, 그 지식을 룰·데이터·Agent 설계로 옮길 수 있게 한다.
- 구성: 강의 노트 6개 모듈(`01`~`06`), 연습문제집(`07`), 모의 클레임 케이스(`08`), 강의 진행안(`09`), 슬라이드 덱(`00-README.md`의 링크). 기존 문서 세트(`../01`~`../09`)·시뮬레이터·영상 3편이 선수 자료다.
- 표기: **[사실]** 표준서식·공개자료·교재로 확인 / **[추론]** 사실에서 도출, 현업 확인 필요 / **[확인 필요]** 원문 대조 전 / **[가정]** 임의 수치 / **[쟁점]** 해석이 갈림. 법률 자문이 아니라 학습 자료다.
