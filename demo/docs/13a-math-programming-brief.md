## 2. 변수

| 종류 | 기호 | 한글 이름 | 뜻 · 왜 필요한가 | 쓰이는 식 |
|---|---|---|---|---|
| 결정 | u[i,b,k] | 시간창선택 (0/1) | 배 i를 부두 b의 k번째 시간창에 댄다. 부두 배정과 "언제쯤"을 한 번에 정하고, 제약 네 가지를 식 없이 지키게 한다 | (1)(2) |
| 결정 | y[i,j] | 앞뒤순서 (0/1) | i가 j보다 먼저. 문서가 묻는 접안 순서 | (3), 후보 |
| 결정 | t[i] | 접안시각 | 예상 작업 종료(호스 분리 = t + 작업)가 여기서 나온다 | (2)~(6) |
| 따라 나옴 | P[i] | 개시시각 | 허용 시간을 세기 시작하는 때 = min(도착 + 통지시간, 접안) | (4)(5)(6) |
| 따라 나옴 | D[i] | 체선시간 | 호스 분리가 개시 + 허용 시간을 넘긴 시간. 목적함수의 유일한 변수 | 목적, (5) |
| 따라 나옴 | O[i,w], β[i,w] | 기상대기, 기상 스위치 | 개시 뒤 접안 전까지 기상 악화 구간 w 때문에 기다린 시간 | (5)(6) |

파라미터: 도착[i], 작업 p[i](접안 → 호스 분리), 허용시간 L[i], 요율 r[i], 통지시간 n[i], 공제비율 ρ[i], 간격 g(호스 분리 → 다음 배 접안, 2h), 시간창 [α, β], 기상 구간, 큰수 M. 선석배정 x[i,b] = Σ_k u[i,b,k].

시간창: 갈 수 없는 부두(제품)는 변수를 만들지 않고, 도착 전·앞 배·조석 시간창 밖·일몰~일출·기상 악화를 뺀 나머지가 시간창이다. 예: 가상 시나리오의 V1(원유, 흘수 20.5 m, 일출~일몰에만 접안)을 부이에 댈 수 있는 때는 사흘 동안 D1 06:53~07:10, D1 15:35~17:21, D2 06:54~08:00, D3 06:55~08:50, D3 17:15~17:19 다섯 번뿐이다.

## 3. 식

```
목적  min Σ_i ( r[i] ÷ 24 ) × D[i]
      최소화: 선박마다 ( 요율 ÷ 24 ) × 체선시간 을 더한 값

(1)   Σ_b Σ_k u[i,b,k] = 1
      그 배의 시간창선택을 모두 더하면 1                                   (부두별 접안 가능 제품)

(2)   Σ α[i,b,k] × u[i,b,k] ≤ t[i] ≤ Σ β[i,b,k] × u[i,b,k]
      고른 창의 창시작 ≤ 접안시각 ≤ 고른 창의 창끝                          (조석 · 일출·일몰 · 기상)

(3)   t[j] ≥ t[i] + p[i] + g − M × ( 3 − y[i,j] − x[i,b] − x[j,b] )
      t[i] ≥ t[j] + p[j] + g − M × ( 2 + y[i,j] − x[i,b] − x[j,b] )
      뒤 배 접안시각 ≥ 앞 배 접안시각 + 앞 배 작업 + 간격                    (한 부두에 한 척)

(4)   P[i] ≤ t[i] ,   P[i] ≤ 도착[i] + n[i]
      개시시각 ≤ 접안시각,  개시시각 ≤ 도착 + 통지시간                       (계약: 언제부터 세는지)

(5)   D[i] ≥ t[i] + p[i] − P[i] − L[i] − ρ[i] × Σ_w O[i,w] ,   D[i] ≥ 0
      체선시간 ≥ 호스 분리 − 개시시각 − 허용 시간 − 공제비율 × 기상대기

(6)   O[i,w] ≤ ( 기상끝[w] − 기상시작[w] ) × β[i,w]
      O[i,w] ≤ t[i] − 기상시작[w] + M × ( 1 − β[i,w] )
      O[i,w] ≤ 기상끝[w] − P[i] + M × ( 1 − β[i,w] )
      기상대기 ≤ 기상 악화 구간 중 개시시각부터 접안시각 사이에 든 시간      (계약: 기다린 시간을 빼 주는지)

후보  Σ_i x[i, 방금 그 부두] + Σ_(이웃한 앞뒤) y[앞, 뒤] ≤ ( 항의 개수 ) − 1
      방금 찾은 배정과 순서 중 적어도 한 군데는 달라야 한다 → 다시 풀면 2안, 3안
```

큰 수 M: `− M × ( … )`의 괄호가 0이면 식이 켜지고 1 이상이면 꺼진다. P는 클수록, O는 클수록 체선이 줄어서 상한만 걸면 솔버가 규칙대로의 값까지 올린다.

## 4. 숫자를 넣어 보면 — SC-01 (손계산 정답)

시각은 첫날 00시부터 지난 시간. 부두는 07시부터 쓸 수 있고 간격은 2. 변수 9개(0/1 3개), 제약 12줄.

```
        도착   도착 + 통지시간   작업 p   허용 시간 L   시간당 요율
  X      2          8            16         24          2,000
  Y      4         10            10         12          4,000

목적  min 2000 × D[X] + 4000 × D[Y]
(2)   7 ≤ t[X] ≤ 144 ,  7 ≤ t[Y] ≤ 144
(3)   y = 1 (X 먼저): t[Y] ≥ t[X] + 16 + 2        y = 0 (Y 먼저): t[X] ≥ t[Y] + 10 + 2
(4)   P[X] ≤ t[X], P[X] ≤ 8 ,  P[Y] ≤ t[Y], P[Y] ≤ 10
(5)   D[X] ≥ t[X] + 16 − P[X] − 24 ,  D[Y] ≥ t[Y] + 10 − P[Y] − 12

y = 0 (Y 먼저)                                 y = 1 (X 먼저)
  t[Y] = 7 → P[Y] = min(10, 7) = 7 → D[Y] = 0     t[X] = 7 → P[X] = min(8, 7) = 7 → D[X] = 0
  t[X] = 7 + 10 + 2 = 19 (식 3 등호)              t[Y] = 7 + 16 + 2 = 25 (식 3 등호)
  P[X] = 8 → D[X] = 19 + 16 − 8 − 24 = 3          P[Y] = 10 → D[Y] = 25 + 10 − 10 − 12 = 13
  목적 = 2000 × 3 = 6,000  ← 최적                  목적 = 4000 × 13 = 52,000
```

## 5. 가상 시나리오 BR-01과 검증 [사실, 2026-11-10]

부두 3곳(1부두 경유·휘발유, 2부두 경유·화학, 부이 원유)·선박 7척, 강풍 D2 09:00 ~ D3 03:00. 변수 71개(0/1 44개), 제약 79줄.

| 안 | 부두별 순서 | 총 예상 체선료 | 기준안 대비 | 위반 |
|---|---|---|---|---|
| 기준안 (도착 순서) | 1부두 V4 → V5 · 2부두 V3 → V6 → V7 · 부이 V1 → V2 | $48,868.06 | | 0 |
| 1안 | 1부두 V4 → V6 · 2부두 V3 → V5 → V7 · 부이 V1 → V2 | $18,868.06 | −$30,000.00 | 0 |
| 2안 | 1부두 V4 · 2부두 V3 → V5 → V7 → V6 · 부이 V1 → V2 | $21,534.72 | −$27,333.34 | 0 |
| 3안 | 1부두 V3 → V4 → V6 · 2부두 V5 → V7 · 부이 V1 → V2 | $29,368.06 | −$19,500.00 | 0 |

기준안은 먼저 온 V6(허용 36h, 하루 $16,000)가 강풍 전 마지막 자리를 차지해 급한 V5(허용 12h, 하루 $36,000, 기상 공제 없음)가 20시간 체선한다($30,000). 1안은 그 자리를 V5에게 준다. 어느 안에서나 남는 $18,868은 V2(원유)가 조석·일출·일몰·강풍에 막혀 D3 06:55에야 접안해서 생긴다.

| 문서가 요구한 검증 | 방법 | 결과 |

| 손계산 정답과 일치 | SC-01의 두 순서 | 52,000과 6,000 모두 일치 |

| 기준안보다 줄인 금액 | 도착 순서 기준안과 비교 | BR-01 −$30,000 · 무작위 300사례 중 43사례에서 더 낮고, 더 높은 사례 0 |
| 제약 위반 | 일정마다 제품·도착·조석·일출·일몰·기상·겹침을 모델과 따로 검사 | 0건 |

## 6. 한계

- 가상 데이터. 일출·일몰은 울산 계산값이고 공공데이터포털 값으로 바꿔야 한다.
- 문서 1절의 조건 데이터 중 제품 생산·출하 계획과 탱크·설비 제원은 아직 식에 없다(날짜별 재고 식으로 넣을 수 있다 — 13b의 식 7).
- 기상으로 기다린 시간을 "개시 뒤 접안 전까지 기상 악화 구간에 든 시간"으로 정했다. 계약서에서 확인할 값이다.
- 작업 시간과 간격(2h)은 가정이다.
