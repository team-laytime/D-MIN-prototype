- Daylight 적용 흐름(PPT 10쪽)을 받지 못해 팀 요구사항 FR-25 문장대로 구현했습니다(Laycan 분기 ①②③ 먼저, ④만 Daylight 식).
- '기상 체선 시간'은 '기상 제한이 없었다면 접안했을 시각 ~ 실제 ETB' 중 체선 기간에 든 시간으로 정의했습니다(정의 확인 필요).
- 작업시간·호스분리 소요는 입력값 또는 가상 과거 실적의 평균 Rate·최빈값입니다.
- 의도적으로 접안을 늦추는 안(예: Laycan From까지 기다렸다 접안)은 탐색하지 않습니다 — ETB는 늘 '가장 이른 가능 시각'입니다.
