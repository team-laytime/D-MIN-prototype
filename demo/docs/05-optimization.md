## 1. 문제 한 줄

> 이동 가능한 선박마다 **부두와 그 부두에서의 순서**를 정해, 모든 제약을 지키면서 **총 예상 체선료**를 가장 작게 하는 일정 3개를 찾는다. 접안 시각은 정하지 않는다 — 순서가 정해지면 '모든 조건을 만족하는 가장 이른 시각'이 하나로 정해진다.

## 3. 변수와 시각

| 기호 | 한글 이름 |
|---|---|
| xᵢ_b ∈ {0, 1} | 선박 i를 부두 b에 배정 |
| πᵇ | 부두 b에 붙는 선박의 순서 |
| tᵢ | ETB(접안 시각) — 순서가 정해지면 아래 식으로 결정됨 |

```
Sᵢ = tᵢ + δ          Eᵢ = Sᵢ + wᵢ_b          Hᵢ = Eᵢ + hᵢ_b          Uᵢ = Eᵢ + ε
작업시작 = ETB + 1시간,  작업완료 = 작업시작 + 작업시간,  호스분리 = 작업완료 + 호스분리 소요,  이안(ETU) = 작업완료 + 2시간
```

## 4. 목적함수 — 총 예상 체선료

```
min  Σᵢ∈𝒱∪𝒱ᶠ  Cᵢ(tᵢ)
최소화  모든 선박의 예상 체선료 합

Cᵢ(t) = rᵢ / 24 × max(0,  Hᵢ(t) − (Pᵢ(t) + Lᵢ) − ρ · Wᵢ(t))
선박 체선료 = 하루 체선료 ÷ 24 × max(0, 호스분리 − 정박종료 − 기상 체선 시간 × 1/2)

Pᵢ(t) = ① t                     eᵢ < Fᵢ 이고 t < Fᵢ        (Early Loading)
        ② t                     eᵢ > Tᵢ                    (Laycan Miss)
        ③ day(Fᵢ) + 06:00       eᵢ < Fᵢ                    (조기 도착)
        ④ min(eᵢ + 6h, t)       그 밖                       (원유선·제품선은 Daylight 식)
정박개시 = 위 네 갈래 중 하나 (PPT 09쪽, LAY-02~06)

Wᵢ(t) = | [tᵢ⁰, t) ∩ [Pᵢ + Lᵢ, Hᵢ] |,   tᵢ⁰ = 기상 제한이 없었다면의 ETB
기상 체선 시간 = '기상이 없었다면 접안했을 시각 ~ 실제 ETB' 중 체선 기간(정박종료 ~ 호스분리)에 든 시간
```

## 5. 제약

```
(1) Σ_b∈ℬᵢ xᵢ_b = 1                                   선박마다 갈 수 있는 부두 하나
(2) tᵢ ≥ aᵢ + d_b                                     ETA + Direction 전에는 접안 불가            ETB-01
(3) j가 같은 부두에서 i 바로 다음이면  tⱼ ≥ Uᵢ + s_b      앞 배 이안 + Switching 뒤에 접안           ETB-01
(4) 다음 선박이 FIX k이면  Uᵢ + s_b < tₖ                 FIX 접안 시각까지 비켜 줘야(같은 시각도 불가) ETB-02
(5) tᵢ ∉ Ω_b,  (GRT ≥ 3만) tᵢ mod 24h ∉ [02:00, 08:00),  (Last POB 대상) tᵢ ≥ Rᵢ
    부두 제한·새벽 금지창·Last POB 해제 전에는 접안 불가                                        ETB-07·04·03
(6) 흘수 ≥ 기준이면  tᵢ ∈ Θ_b                           조석 시간창 안에서만 접안                  ETB-08
(7) (i, j) ∈ 𝒞이면  [tᵢ, Uᵢ − 2h) ∩ [tⱼ, Uⱼ − 2h) = ∅   동시 작업 금지(상대 ETU − 2시간까지 대기)  ETB-05·06
(8) 일말 재고ₐ ∈ [최소, 용량]                          작업시작일 기준 재고 범위                    ETB-09
(9) tᵢ ≤ 마감ᵢ                                         출하 마감                                  ETB-11
(10) 고정 선박 k ∈ 𝒱ᶠ:  tₖ = 입력값                     FIX·작업 중 선박은 움직이지 않음            FR-10·11
```

## 6. 풀이

### 6-1. 디코더 — 순서를 시각으로 바꾸기

계획 = [(선박, 부두), …] 우선순위 목록. 앞에서부터 그 부두의 '다음 순서'로 붙이며, 각 선박의 ETB는 '(2)~(9)를 모두 만족하는 가장 이른 시각'입니다(`etb.place`, 밀어내기). 같은 함수가 기준안·후보·민감도에 모두 쓰입니다.

### 6-2. 기준안 (OPT-01, FR-34)

ETA 순서대로, 접안 가능시각이 가장 이른 부두에 붙입니다(동률이면 부두 표 순서). '비교용 기준안(현행 실적 아님)'으로 표시합니다.

### 6-3. 지역 탐색과 반복 지역 탐색

기준안에서 출발해 '부두 바꾸기 → 두 척 맞바꾸기 → 한 척 끼워 넣기' 중 개선되는 첫 이동을 받아들입니다. 선박이 10척 이상이면 제한시간의 40% 동안 '조금 흔들기(2~3번 맞바꾸기) → 다시 지역 탐색'을 반복합니다(시드는 시나리오 지문에서 뽑아 재현 가능). 여기서 나온 좋은 해가 분기한정의 '이미 찾은 3번째 후보 금액'(가지치기 기준)이 됩니다.

### 6-4. 분기한정 탐색 (Branch & Bound)

깊이 우선으로 한 번에 (선박, 부두) 하나를 붙입니다.

**정리 1 — ETB가 줄지 않는 순서만 봐도 된다.** 디코더가 만들 수 있는 모든 일정 σ는 'ETB 오름차순으로 한 척씩 붙이기'로 그대로 다시 만들 수 있다.

> 증명 요지: σ를 ETB 순으로 정렬해 앞에서부터 붙인다. 선박 j를 붙일 때 σ에서 j보다 늦게 접안한 선박 k가 j를 민 적은 없다 — k가 j를 밀었다면 j는 k의 작업완료(또는 이안 + Switching) 뒤로 갔을 것이므로 σⱼ > σₖ가 되어 모순이다. 그러므로 'j보다 먼저 접안한 선박만 보고 구한 가장 이른 가능 시각'이 σⱼ와 같다. 앞에서부터 귀납.
> 쓰임: 자식 노드 중 ETB가 앞 노드보다 이른 것은 버린다 → 같은 일정을 여러 순서로 만드는 낭비가 사라진다.

**정리 2 — 하한.** 남은 선박 r이 부두 b에서 지금 붙을 수 있는 가장 이른 시각을 t_rb라 하면, 앞으로 r의 ETB는 max(t_rb, 방금 붙인 배의 ETB)보다 이르지 않다(제약이 늘기만 하므로). 체선료는 ETB가 늦어지면 줄지 않는다 — **단 하나의 예외**: eᵢ < Fᵢ인 배가 Laycan From 직전(정박개시 = ETB)에서 직후(정박개시 = From 06:00)로 넘어가면 정박개시가 늦어져 체선 시간이 줄 수 있다. 그래서

```
LBᵣ = min_b  min( Gᵣ(t),  Gᵣ(max(t, Fᵣ)) ),    t = max(t_rb, 직전 ETB)
남은 선박 하한 = 부두마다 가장 이르게 붙었을 때 체선료, Laycan From을 넘는 지점과 비교해 작은 값
```

Gᵣ는 기상 공제를 '기다린 시간이 전부 기상 탓'인 최대치로 잡은 체선료입니다(하한이 실제보다 커지지 않게). 노드 하한 = 지금까지 금액 + Σ 남은 선박 하한. 하한 ≥ 지금까지 찾은 K번째 후보 금액이면 그 가지를 버립니다.

**상태 병합.** 열쇠 = (붙인 선박 집합, 부두별 마지막 선박과 ETU, 아직 작업 중인 선박들의 (부두, 선박, ETB), 마지막 ETB, 재고 증감). 열쇠가 같으면 남은 선박의 가능한 미래가 같으므로, 같은 열쇠는 금액이 낮은 K개까지만 계속 탐색합니다(후보 K개의 정확성 유지).

**출력.** 제한시간(기본 20초) 안에 끝나면 1안은 '최적 증명'. 못 끝나면 '최선 탐색 결과'와 최적성 갭 = (1안 − 하한) ÷ 1안. 하한은 스택에 남은 노드 하한의 최솟값입니다. 후보는 부두별 순서가 1척이라도 달라야 하고(FR-35), 독립 검증기를 통과한 것만 남깁니다.
